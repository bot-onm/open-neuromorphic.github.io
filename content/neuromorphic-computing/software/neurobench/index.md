## Overview

It addresses the issue of the lack of benchmarks for neuromorphic computing.

It hosts multiple tasks and formats including event data.

Its target are researchers working in state-of-art architectures and training methods that could benefit by having a clear leader board to optimize, and a easy way to run the evaluations.
